# 股息追踪 Portfolio

本地使用的股票持仓管理工具，支持 A 股（沪市 / 深市 / 北交所）。

## 功能

- **持仓管理** — 添加、行内编辑、删除股票持仓（删除需二次确认）
- **关注列表** — 记录未持有的股票，只看现价与涨跌幅，不参与盈亏统计，可一键「转为持仓」
- **实时行情** — 自动获取最新价、昨收价与股息率（数据来源：腾讯行情接口）
- **盈亏计算** — 基于最新价计算市值、成本、盈亏、盈亏率、当日盈亏、持仓占比及各项汇总
- **股息分析** — 显示每只股票的股息率、预计年度分红，以及按市值加权的组合平均股息率
- **股息率目标价** — 按 5.0% ~ 8.5% 共 8 档目标股息率反推对应股价，现价已满足的档位高亮
- **智能识别** — 输入 6 位代码自动识别市场并填充名称、现价、昨收价、股息率
- **排序与搜索** — 点击表头排序，按名称或代码前缀实时过滤
- **自动刷新** — 默认每 5 秒静默刷新行情，可在标题栏开关（刷新不打断正在编辑的内容）
- **导入 / 导出** — 导出 JSON 备份，或从 JSON 覆盖恢复（含持仓与关注）
- **数据持久化** — 数据存储在浏览器 localStorage，关闭页面不丢失

## 使用

直接打开 `Interest.html` 即可使用。

实时行情功能在 `file://` 协议下可能受限，如果遇到行情刷不出来，运行：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/Interest.html`。

## 数据存储

所有数据存储在浏览器本地存储（localStorage）中，不会上传到任何服务器。

## 测试

应用本身双击即用、无需构建；改代码后可用一组无头用例回归（jsdom 加载页面 + 桩行情，不联网）：

```bash
npm install
npm test
```

详见 [test/README.md](test/README.md)。

## 股票代码格式

输入统一为 6 位数字代码，程序自动补市场前缀：

| 市场 | 代码开头 | 前缀 | 示例 |
|------|----------|------|------|
| 沪市 | 6 / 9 / 5 | sh | 600519 |
| 深市 | 0 / 3 / 2 / 1 | sz | 000858 |
| 北交所 | 8 / 4 | bj | 430047 |
