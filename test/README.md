# 测试用例

针对单文件应用 `Interest.html` 的无头测试。用 [jsdom](https://github.com/jsdom/jsdom) 真实加载页面并执行其中全部脚本，再把行情接口替换成可控的桩，因此**测试不联网、不依赖腾讯接口**。

只在开发/改代码时需要 Node 环境；应用本身依然是「双击 HTML 即可用」，不需要构建。

## 运行

```bash
npm install   # 仅首次，安装 jsdom
npm test
```

全部通过时退出码为 0，任意一条失败为 1（可直接接进 CI）。整轮约 60~80 秒，其中大部分时间是在等应用自身的 5 秒自动刷新定时器真实触发。

## 用例分组

| 文件 | 说明 |
|------|------|
| `suites/smoke.js` | 页面无报错加载、空状态、示例数据、汇总口径（市值/成本/盈亏/当日盈亏/年分红/加权股息率） |
| `suites/bugs.js` | 缺陷复现：这些用例在修复提交 `212bca6` 之前全部失败，用于防止回归 |
| `suites/regression.js` | 修复后的行为 + 常规端到端流程：编辑、搜索、排序、导入导出、自动/手动刷新、行内编辑保护 |

`bugs.js` 覆盖的缺陷：

1. 编辑持仓丢失 `prevClose`，当日盈亏被清零并持久化
2. 手工改动代码/现价后沿用上一只股票的昨收价与涨跌幅
3. 记录 `name` 非字符串时搜索抛 `TypeError`
4. 存在编辑行（或编辑行被页签隐藏/搜索过滤）时自动刷新永久停摆
5. 「刷新行情」重绘清掉正在编辑的内容
6. 目标价表「无股息数据」行 `colspan` 错位
7. 关闭自动刷新后切回标签页仍发请求

## 结构

```
test/
├── run.js              # 入口：依次跑各分组并汇总
├── check.js            # 极简断言收集器
├── harness.js          # jsdom 加载器 + 行情桩 + DOM 操作小工具
├── gbk-names.json      # 股票名称的 GBK 字节夹具
└── suites/             # 各分组用例
```

## 关于行情桩

`harness.js` 的桩返回**字节级真实**的响应：股票名称字段用 GBK 编码（取自 `gbk-names.json`），其余字段为 ASCII，从而走通应用里 `new TextDecoder('gbk')` 的解码路径，能验证中文名称是否正确落到表格中。

支持的桩配置（`H.load({ quotes, storage })`）：

- `quotes[code]`：单个报价对象；数组表示按调用次序返回（用于模拟价格变化）；`'NOTFOUND'` 或省略表示接口返回空数据
- `storage`：预先写入 `localStorage` 的键值，用于构造历史/异常数据
